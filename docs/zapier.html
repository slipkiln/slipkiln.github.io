Use SlipKiln with Zapier

Create branded PDF invoices, receipts and certificates from any app Zapier connects to. No code needed. Every PDF counts toward your plan the same as an API call.

Connect your account

  1. Get a free API key (50 documents a month). Keys start with sk_.
  2. Open the SlipKiln Zapier invite link and accept it (SlipKiln is in Zapier beta, so it doesn't show in Zapier search yet). Then create a Zap and pick SlipKiln as an action app.
  3. When Zapier asks you to sign in, paste your API key and click Yes, Continue. Zapier checks the key and shows the connection under your plan name.

Keep your key private. If it leaks, email support@slipkiln.com and we'll rotate it.

Actions

Create PDF From Template

Makes a branded invoice, receipt or certificate from your data.

FieldNotes
Template (required)Invoice, Receipt or Certificate. See the template gallery.
Data (JSON) (required)The template's fields as JSON. Map values from earlier steps into it.
File NameDefaults to document.pdf.
Paper SizeLetter, A4, A5 or Legal.

Create PDF From HTML

Turns your own HTML and CSS into a PDF.

FieldNotes
HTML (required)A full HTML page. Images must be data: URIs, because rendering has no network access.
File NameDefaults to document.pdf.
Paper SizeLetter, A4, A5 or Legal.
LandscapeYes or No. Default is No.

Both actions return PDF File (a file later steps can attach or upload), File Name and Documents This Month.

Example Zaps

Form → certificate by email

Google Forms new response → SlipKiln Create PDF From Template (Certificate) → Gmail send email with the PDF File attached.

Paid order → receipt in Drive

New Shopify or WooCommerce order → SlipKiln Create PDF From Template (Receipt) → Google Drive upload file.

New row → invoice

Google Sheets new row → SlipKiln Create PDF From Template (Invoice) → Gmail or Outlook send email.

Custom report → Dropbox

Schedule by Zapier (weekly) → Formatter builds HTML → SlipKiln Create PDF From HTML → Dropbox upload file.

Example invoice data for the Data (JSON) field:

{"number":"INV-{{Row}}","issue_date":"{{Date}}","due_date":"{{Due Date}}","currency":"USD",
 "customer":{"name":"{{Name}}","email":"{{Email}}"},
 "items":[{"description":"{{Item}}","qty":1,"unit_price":{{Amount}}}]}

Field names vary by template. Copy the exact sample from the template gallery.

Tips & limits

  • Zap runs use your plan's documents. On the free plan, runs after 50 documents in a month fail with quota_exceeded until the next month or an upgrade on the Billing page.
  • Failed renders don't count against your quota.
  • Requests up to 2 MB, PDFs up to 20 MB, 15 seconds per render. See limits.
  • Documents are processed in memory and not stored after Zapier receives them.

Help

Zap erroring? Check the error code in your Zap history against the error table, or email support@slipkiln.com.
