HTML to PDF in Make

Use Make's HTTP module to call SlipKiln and get a PDF file you can pass to email, Google Drive or any other module.

Get a free API key

Set up the request

  1. Get a free API key (starts with sk_).
  2. In Make, add the HTTP > Make a request step. Method POST, URL https://api.slipkiln.com/v1/render/template (or /v1/render/html for your own HTML).
  3. Add a header Authorization: Bearer YOUR_KEY and send a JSON body, for example {"template":"invoice","data":{...}}. Map fields from earlier steps into data.
  4. Set the response to be treated as a file (binary). The output is the PDF, ready to email, upload to cloud storage or attach to a record.

For /v1/render/html, send {"html":"<h1>Hello</h1>","options":{"format":"A4"}}. Options: format (A4, A5, Letter, Legal), landscape, margin, print_background.
