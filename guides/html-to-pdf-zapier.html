HTML to PDF in Zapier

SlipKiln has its own Zapier app with two actions: Create PDF From Template and Create PDF From HTML.

Get a free API key

How it works

  1. Get a free API key.
  2. Follow the Zapier setup guide to add SlipKiln to your Zapier account and connect it with your key.
  3. Add a SlipKiln action after any trigger, such as a new Stripe payment, form entry or spreadsheet row, and map fields into it.
  4. Use the PDF file in the next step: attach it to an email, save it to Google Drive or Dropbox.

Prefer raw HTTP? Zapier's Webhooks step can call the API directly, the same way as in Make.
