Invoice PDF API

Send your invoice data as JSON and get a clean, itemized PDF back. No HTML to design, no headless browser to run.

Get a free API key

One call per invoice

curl -s https://api.slipkiln.com/v1/render/template \
  -H "Authorization: Bearer $KEY" -H "content-type: application/json" \
  -d '{"template":"invoice","data":{"number":"INV-1","currency":"USD","customer":{"name":"Acme"},"items":[{"description":"Work","qty":2,"unit_price":50}]}}' \
  -o invoice.pdf

The built-in invoice template handles line items, tax, totals, due date and your business details. Need your own layout? Post HTML to /v1/render/html instead.
