JSON to PDF API

Post JSON, get a PDF. Pick a built-in template or send HTML and CSS.

Get a free API key

Templates

  • Invoice: itemized, tax, totals, due date (A4)
  • Receipt: compact payment receipt (A5)
  • Certificate: landscape completion or achievement certificate

List them, with example data, at GET /v1/templates.

Example

curl -s https://api.slipkiln.com/v1/render/template \
  -H "Authorization: Bearer $KEY" -H "content-type: application/json" \
  -d '{"template":"invoice","data":{"number":"INV-1","currency":"USD","customer":{"name":"Acme"},"items":[{"description":"Work","qty":2,"unit_price":50}]}}' \
  -o invoice.pdf
