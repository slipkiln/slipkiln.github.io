How it works

01

Get an API key

Sign up, add your logo and brand colors once.

02

POST your data

Send JSON to a ready-made template, or your own HTML/CSS.

03

Get a PDF

Receive the file directly, or a signed URL / webhook for async jobs.

Try it

curl https://api.slipkiln.com/v1/render \
  -H "Authorization: Bearer $SLIPKILN_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "template": "invoice",
    "data": {
      "number": "INV-1042",
      "customer": { "name": "Acme Co." },
      "items": [{ "description": "Consulting", "qty": 10, "unit_price": 120 }],
      "currency": "USD"
    }
  }' \
  -o invoice.pdf
# → invoice.pdf, branded with your logo and colors
