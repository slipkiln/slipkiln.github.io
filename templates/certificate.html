Certificate PDF API

Generate course and award certificate PDFs from JSON, with your brand color. Free for 50 documents a month.

Get a free API keyRead the docs

1. Save this as certificate.json

{
  "template": "certificate",
  "data": {
    "brand": {
      "name": "Northwind Studio",
      "color": "#0f766e",
      "email": "billing@northwind.example",
      "website": "northwind.example",
      "address": [
        "100 Market St",
        "Denver, CO 80202"
      ]
    },
    "title": "Certificate of Completion",
    "recipient": "Jamie Rivera",
    "description": "for successfully completing the Advanced Data Visualization course (24 hours).",
    "date": "October 15, 2026",
    "signer": {
      "name": "Morgan Lee",
      "title": "Program Director"
    },
    "certificate_id": "NW-2026-00412"
  }
}

2. Render it

curl -X POST https://api.slipkiln.com/v1/render/template \
  -H "Authorization: Bearer $SLIPKILN_KEY" \
  -H "Content-Type: application/json" \
  -d @certificate.json \
  -o certificate.pdf

You get back a PDF. Change brand.color and brand.name to match your business. All text is HTML-escaped. Need a custom layout? Send your own HTML to /v1/render/html.
