Receipt PDF API

Turn payment data into clean, branded receipt PDFs with one API call. Free for 50 documents a month.

Get a free API keyRead the docs

1. Save this as receipt.json

{
  "template": "receipt",
  "data": {
    "brand": {
      "name": "Northwind Studio",
      "color": "#0f766e",
      "email": "billing@northwind.example",
      "website": "northwind.example",
      "address": [
        "100 Market St",
        "Denver, CO 80202"
      ]
    },
    "number": "RCPT-88213",
    "date": "2026-10-15",
    "payment_method": "Visa \u2022\u2022\u2022\u2022 4242",
    "currency": "USD",
    "tax_rate": 0,
    "customer": {
      "name": "Jamie Rivera"
    },
    "items": [
      {
        "description": "Pro plan (monthly)",
        "qty": 1,
        "unit_price": 19
      },
      {
        "description": "Extra seats",
        "qty": 2,
        "unit_price": 5
      }
    ]
  }
}

2. Render it

curl -X POST https://api.slipkiln.com/v1/render/template \
  -H "Authorization: Bearer $SLIPKILN_KEY" \
  -H "Content-Type: application/json" \
  -d @receipt.json \
  -o receipt.pdf

You get back a PDF. Change brand.color and brand.name to match your business. All text is HTML-escaped. Need a custom layout? Send your own HTML to /v1/render/html.
